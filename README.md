# 目押しトレーナー

スロットの目押し（ビタ押し・BIG/REG揃え・チェリー狙い）をスマホのブラウザで練習できるWebアプリです。

- ビタ押し計測: 狙った図柄から何コマ・何msずれたかを表示
- 揃え練習: 最大4コマの引き込みありで「揃った / ハズレ」を判定し、連続成功数を表示
- 履歴: モード別の成功率・平均ずれ・最高連続成功数、日ごとの成功率（端末のブラウザに保存）

図柄はすべて自作の簡易図形です。メーカーの図柄画像・商標は使用していません。

## 開発

```sh
npm install
npm run dev    # 開発サーバー（LAN内のスマホからもアクセス可）
npm test       # テスト
npm run build  # dist/ に静的ファイルを出力
```

機種データは `src/machines/*.json` に置くと機種選択に自動で追加されます。
